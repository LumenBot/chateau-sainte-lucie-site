# Rendus de projection — USAGE INTERNE, NE JAMAIS PUBLIER

Les rendus photoréalistes des futurs aménagements des suites sont des outils de
décision **internes**. Ils ne sont volontairement **pas** versionnés dans ce
dépôt (public) et ne doivent jamais être copiés dans `src/assets`, `public`,
les métadonnées sociales (Open Graph) ou la galerie.

Seules les **photographies réelles** présentes dans `src/assets/images/` peuvent
être publiées. Les photographies définitives des suites seront réalisées après
travaux, en mars 2027.
